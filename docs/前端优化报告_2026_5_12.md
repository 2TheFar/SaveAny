# SaveAny 前端优化报告

日期：2026-05-12  
范围：首页流程、沉浸式视觉、下载主路径、AI 功能入口、使用说明页

## 背景

本次优化前，SaveAny 首页同时承载“解析下载”和“工作台/AI 功能”的表达，用户进入后容易误以为首页已经是完整工作台，下载主流程也不够清晰。尤其在解析完成后直接跳转功能页，会让“保存视频”这一核心能力被 AI 功能弱化。

本轮目标是把首页重新定位为用户面向的保存入口：先建立品牌感和服务可信度，再通过整屏滑动进入实际保存工具。AI 总结、字幕、导图和问答保留为进阶入口，不再抢首页主任务。

## 已完成优化

### 1. 首页流程回归保存主路径

- 解析成功后保留在首页，不再自动跳转 `/workspace`。
- 首页第二屏展示封面、标题、来源、时长、画质选项、Bilibili 登录入口和保存按钮。
- 下载动作改为用户手动触发，保存完成后显示本地文件链接。
- 解析结果区保留“更多 AI 功能”入口，跳转到 `/workspace?url=...`。

### 2. 两屏沉浸式首页

- 首页改为两段式吸附滚动：
  - 第一屏：蓝色品牌介绍页。
  - 第二屏：白色保存工具页。
- 使用 CSS `scroll-snap` 实现整屏滑动，不做复杂滚轮劫持。
- 移动端使用更温和的吸附策略，避免滚动卡住。
- `prefers-reduced-motion` 下关闭强滚动动效。

### 3. 首屏品牌与文案

- 主标题调整为 `SaveAny`。
- 宣传语调整为 `世间万物它皆为我所用`。
- 顶部徽章改为“视频保存助手”，去除“公开”措辞。
- 首屏 CTA 保留“开始保存”和“查看支持规则”。
- 优势卡改成用户收益表达：多平台链接、画质可选、手动保存。

### 4. 产品预览式图形 UI

- 右侧视觉从抽象流程图改成“快速使用”产品预览。
- 预览中包含链接输入、视频信息、平台状态、画质选项和保存展示。
- 预览中的“保存”不再使用真实按钮，避免用户误点无效控件。
- 平台列表改成更克制的 logo wall 风格，减少标签堆叠感。

### 5. 第二屏保存工具优化

- 标题改为“把视频保存到本地”，去掉“保存工具”等偏工程化小标题。
- 空状态文案改为“粘贴一个视频链接开始”。
- 空状态大白框重新排版，平台按钮改成对称网格。
- 结果区按钮统一为“保存”，加载态为“保存中...”。
- 长标题、长文件名和画质按钮都允许换行，减少移动端溢出风险。

### 6. 使用说明独立页面

- 新增 `/guide` 使用说明页。
- 首页不再堆叠教程、规则和底层逻辑。
- 使用说明页说明保存主流程、Bilibili 登录、高质量保存和 AI 功能入口。
